# V3.7.3

Targeted polish on top of V3.7.2.

- Kept the existing quick-action dumbbell and corrected its centering/alignment.
- Changed the Note pencil to a mostly vertical writing-pencil angle.
- Replaced bottom navigation glyphs with matching outline SVG icons at one size/style.
- Prevented Money and Thesis Budget headers from looking detached/floating on Android.
- Centered Focus Timer ring, presets, custom duration, controls, and help text.
- Generic Focus Timer no longer triggers thesis-roadmap review.
- Scheduled Thesis blocks now schedule a Thesis-session-finished review notification at the end of their schedule block (next scheduled activity).
- Full Schedule displays the derived Thesis session duration.
- Open Budget now includes Proposal / Panel Defense and Panel Food directly.
- Proposal / Panel Defense and Panel Food are checkable Paid/Not Paid items using the same typography as BOM rows.
- Other thesis costs support edit, add, delete, planned cost, actual cost, and paid status.
- Thesis Cost progress uses paid planned cost when no actual cost has been entered, so checking those costs updates the bar immediately.
- Preserved Android applicationId/namespace `com.edjay.lifeorganizer` and permanent-signing GitHub workflows.
- Version: 3.7.3 (versionCode 8).
